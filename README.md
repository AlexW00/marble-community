# Marble

Expense allowances and savings goals, represented by glass jars filled with colored marbles. Use Marble on your own or share a jar while keeping individual balances.

Marble is being prepared for its first release on iPhone and iPad, running iOS 26 or iPadOS 26 and later. It records virtual money only; it does not connect to bank accounts or move real money.

This repository hosts community discussions and public policies. Issues are disabled; please use Discussions instead. Marble's app source code is maintained separately.
